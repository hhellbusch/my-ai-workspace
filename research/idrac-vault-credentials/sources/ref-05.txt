# Credential Vault (Secure Connect Gateway 5.x Application Edition)

A credential vault stores certificates and credentials centrally without storing them locally on SCG.

Supported credential vaults:
- CyberArk with Conjur API
- CyberArk Credential Provider
- Azure Key Vault
- HashiCorp Vault

The Credential vaults page supports add/edit/delete and shows vault name, vault server name, connectivity status, type, and update time. After adding a vault, create account credentials by mapping the credential vault account ID.
