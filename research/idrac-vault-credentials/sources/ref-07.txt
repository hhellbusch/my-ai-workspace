# Create a credential vault — Hashicorp Vault (SCG REST API)

URI: POST `/v2/inventory/remoteCredentialVaults`
Content-type: application/json
Authorization: Bearer

Request body:
```
{
  "VAULTNAME": "string",
  "VAULTHOSTNAME": "string",
  "VAULTPORT": "8200",
  "AUTHMETHOD": "String",
  "ORGACCOUNTNAME": "string",
  "CLIENTLOGINNAME": "string",
  "VAULTAPIKEY": "",
  "USERNAME": "string",
  "PASSWORD": "string",
  "VAULTTYPE": "HASHICORPVAULT"
}
```

AUTHMETHOD options: LDAP, Username, Token, or JWT (matching vault-side setup).
- LDAP or Username → Username/Password = credentials
- Token → Username: Token, Password: Token
- JWT → Username: ROLE, Password: JWT TOKEN

Also documents Conjur, CyberArk CCP (with p12/pfx cert upload), and Azure Key Vault create payloads on the same page.
