# Credential vault parameters (SCG REST API)

A credential vault stores certificates/credentials for devices managed in SCG. Multiple vaults allowed. Map vault account ID when creating device credentials.

| Parameter | Description |
| --- | --- |
| VAULTNAME | Name assigned to the credential vault |
| VAULTHOSTNAME | Hostname or IP of the vault |
| VAULTPORT | Port (N/A for Azure) |
| CLIENTLOGINNAME | Conjur: client login; CCP: Application ID; Azure: Client ID; **HashiCorp: Path** |
| ORGACCOUNTNAME | Conjur: org account; CCP: Safe name; Azure: Client secret; **HashiCorp: Namespace** |
| VAULTTYPE | CONJUR / CyberArk CCP / AZUREKEYVAULT (HashiCorp uses HASHICORPVAULT on create endpoint) |
| VAULTAPIKEY | Conjur: API key; CCP: identifier from p12/pfx upload; Azure: Tenant ID |
