# Integrating HashiCorp Vault (Dell Telecom Infrastructure Automation Suite)

(Source capture via web-search excerpt — InfoHub blocked by reCAPTCHA for automated fetch)

Configure a KMS to store passwords used by DTIAS. Note (suite 2.5): only HashiCorp Vault Enterprise Version 1.15.5 is supported.

After integration, only BMC credential secrets are stored in Vault (credentials of servers managed by the automation suite).

Prerequisites / setup sketch:
- Running Enterprise Vault reachable from the automation suite cluster
- Vault namespace for the suite cluster
- Policy for CRUD on paths
- 12-hour token for the namespace used at install time

Config file `dtias_config.yaml` fields:
- enable_kms: true
- kms_provider: "vault"
- kms_address: https://host:port
- kms_namespace: <namespace>
- kms_token: <token>
- (2.4 docs also mention kms_ca_string: base64 PEM CA)

BMC credentials can be created by:
- On-boarding a server through APIs
- Vault admin manually creates a secret with specific name/format, then on-boards with secret name
